# E-Laundry Frontend

React + Vite frontend for the E-Laundry platform.

## Prerequisites
- Node.js 18+
- npm 9+

## Setup
```bash
cd frontend
npm install
```

## Run in Development
```bash
npm run dev
```

## Build for Production
```bash
npm run build
```

## Preview Production Build
```bash
npm run preview
```

## Available Scripts
- `npm run dev` - Start Vite development server
- `npm run build` - Build optimized production bundle
- `npm run preview` - Preview the production build locally
- `npm run lint` - Run ESLint checks

## Environment Variables
Create `frontend/.env` and define:

- `VITE_FIRBASE_API_KEY`
- `VITE_GEO_API`

## Tech Stack
- React 19
- Vite
- Redux Toolkit
- React Router
- Tailwind CSS
- Axios
- Firebase
